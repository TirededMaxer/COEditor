# 配置

运行时读取 Steam 容器 `drive_c/.cx-tuner.ini`。每个进程启动时选择自身 EXE 文件名对应节；缺失键从 `[global]` 继承。程序名不区分大小写，但同名 EXE 暂时无法按不同安装目录区分。保存采用原子替换；新游戏进程读取最新文件，正常改参数无需重启 Steam / Sevoflurane。已在运行的游戏不承诺热更新。

| 键 | 值 | 作用 |
| --- | --- | --- |
| mouse | 0 / 1 | 原有路径 / macOS 处理后相对位移 |
| wheel | 0 / 1 | 原有事件 / 物理 HID 刻度 |
| sync | -1 / 0 / 1 | 跟随游戏 / 强制关闭 / 强制开启 |
| drawables | 0 / 2 / 3 | 跟随游戏 / Metal 双缓冲 / 三缓冲 |
| queue | 0 或 1–16 | 跟随游戏 / D3D11 最大排队帧数；界面提供完整 1–16 |
| fps | 0 或 1–1000 | 不额外限帧 / 每秒领取 Metal drawable 的上限 |
| pacing | 0 / 1 / 2 | 关闭 / 均衡 / 低延迟提交节奏 |
| stats | 0 / 1 | 关闭 / 实际呈现帧时间统计 |

应用不再提供预设或参数锁定，各项独立手动调整。旧配置中的 `preset`、`preset_fps` 元数据读取时忽略，下次保存时去掉；同步、缓冲、队列、限帧、提交节奏和输入等实际参数保留原值。新配置的画面设置默认跟随游戏，额外限帧、提交控制与统计默认关闭。

“缓冲数量跟随游戏”和“队列长度跟随游戏”分别写 0。Metal 的合法显式数量为 2 或 3，1 不受 CAMetalLayer 支持。D3D11 队列 1 与 Metal 双缓冲是不同概念。

Steam 客户端三类进程跳过游戏画面覆盖；鼠标与滚轮开关仍根据各自配置决定。输入与 Metal 设置可用于其他程序，具体体感需实测；队列设置需要该游戏的 64 位 D3D11 代理完成注册。

添加游戏通过本地安装清单和 Steam appinfo 识别 Windows 启动路径。未取得可靠启动信息时会提供受限的 EXE 候选供人工选择；不使用账号 API。注册前会检查 PE 架构与已有 DLL / Wine 覆盖。游戏更新后如果代理丢失，维护器会按已登记哈希恢复；若更新写入了不同的 DLL，则保留并提示。

## 帧控制与统计

新参数缺失时均按 0 处理，升级不会自动改变现有游戏手感。移除预设不会重新计算或重置现有参数。通用值按 EXE 配置继承；Steam 基础进程跳过全部画面覆盖。

限帧在 `nextDrawable` 领取下一帧缓冲前用高精度休眠等待，不忙等；游戏自身的更低帧率上限仍然有效。每个 Metal layer 独立节奏，不改游戏内部模拟速度。

提交节奏通过实际呈现回调控制提前量：均衡档允许更多重叠，低延迟档更紧。结合显示刷新周期预测下一帧放行，避免晚到的回调额外串行化一帧。丢弃 drawable、切后台或回调停止时有到期清理和 100 ms 反馈等待上限。该开关不等同于 NVIDIA Reflex，也不修改游戏内部输入采样；不同负载下需比较流畅度和响应。

统计来自 `MTLDrawable.presentedTime`，只收录实际呈现且时间戳有效的帧；不会把 `Present` 调用次数计为显示 FPS。每个曲面保留最近 512 个时间戳，按实际间隔算呈现 FPS、P95/P99、最长间隔和慢端 1% 间隔平均值的倒数。超过 1 秒的暂停开始新窗口，1% Low 至少需要 100 个间隔。

每秒最多写一次当前快照到容器 `drive_c/.cx-frame-stats/<pid>-<layer>.json`，序列化与原子替换在后台队列完成；不开启统计时不写文件。“查看统计”按选中 EXE 筛选，优先显示当前活跃的最大曲面，暂停后保留最后快照。统计仅描述呈现间隔，不是端到端输入延迟测量。JSON 会保留在本机，不上传。

## 输入权限与保存状态

未保存状态以当前草稿与最近成功读取／保存的配置比较。只切换配置范围或控件回写相同值不会生成覆盖；撤销改动恢复保存值后提示清除。关闭“沿用通用输入设置”会显式复制当前输入值，使后续通用修改不再影响该游戏。

`wheel=1` 只是请求使用 HID 刻度；实际读取还需当前负责启动游戏的入口获 macOS 输入监控授权。启动入口重新签名或更新后可能要在系统设置刷新授权并重启该入口。这种权限恢复与普通参数生效是两件事。

## 滚轮读取端

1.5 使用独立协议 2 按需组件，`wheel` 仍为 0/1，不改变 INI 格式。组件与实际就绪状态见 [README](../README.md#独立滚轮读取器157)。关闭优化不会消费物理环事件；缺少授权或读取器心跳失效时保留原生路径。
