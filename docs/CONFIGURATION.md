# 配置

运行时读取 Steam 容器 `drive_c/.cx-tuner.ini`。每个进程启动时选择自身 EXE 文件名对应节；缺失键从 `[global]` 继承。程序名不区分大小写，但同名 EXE 暂时无法按不同安装目录区分。

| 键 | 值 | 作用 |
| --- | --- | --- |
| mouse | 0 / 1 | 原有路径 / macOS 处理后相对位移 |
| wheel | 0 / 1 | 原有事件 / 物理 HID 刻度 |
| sync | -1 / 0 / 1 | 跟随游戏 / 强制关闭 / 强制开启 |
| drawables | 0 / 2 / 3 | 跟随游戏 / Metal 双缓冲 / 三缓冲 |
| queue | 0 或 1–16 | 跟随游戏 / D3D11 最大排队帧数；界面提供 1–4 |
| preset | 0–4 | 界面模式：自定义、游戏默认、流畅优先、均衡、低延迟 |

选择预设时，应用写入明确数值并锁定画面控件。自定义保留当前数值并解锁；即便自定义值碰巧等于预设，也会保留自定义模式。旧配置未写 preset 时，根据已有值推断模式。

“缓冲数量跟随游戏”和“队列长度跟随游戏”分别写 0。Metal 的合法显式数量为 2 或 3，1 不受 CAMetalLayer 支持。D3D11 队列 1 与 Metal 双缓冲是不同概念。

Steam 客户端三类进程跳过游戏画面覆盖；鼠标与滚轮开关仍根据各自配置决定。输入与 Metal 设置可用于其他程序，具体体感需实测；队列设置需要该游戏的 64 位 D3D11 代理完成注册。

添加游戏通过本地安装清单和 Steam appinfo 识别 Windows 启动路径。未取得可靠启动信息时会提供受限的 EXE 候选供人工选择；不使用账号 API。注册前会检查 PE 架构与已有 DLL / Wine 覆盖。游戏更新后如果代理丢失，维护器会按已登记哈希恢复；若更新写入了不同的 DLL，则保留并提示。
