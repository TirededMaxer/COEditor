# COEditor 1.5.5

- 滚轮状态区分未安装、安装异常、启动入口异常、运行故障与正常状态；正常待命和就绪显示绿色对勾，异常显示橙色警告及具体原因。
- 活动状态核对当前读取器 PID 与更新时间，避免陈旧状态误报正常。
- 修正帧率上限输入框自动获取和保留焦点的问题：打开、切回应用时保持中性焦点，点击后仍可编辑，点击空白处、回车或 Esc 结束编辑。
- 增加状态判定和实际窗口焦点回归；保留已授权的协议 2 滚轮组件、现有 Wine 驱动与游戏参数。

本版仅需更新 COEditor.app；现有 1.5.2 驱动和滚轮读取器无需替换或重新授权。构建与安装包继续由 GitHub Actions 生成。

# COEditor 1.5.2

- 改为游戏按需启动滚轮读取器：不登录启动、不空闲常驻；最后一个使用者退出约 1 秒后结束。多个游戏共享进程，崩溃退出也能清理。
- 登记以 PID 和进程创建时间区分，接收端限制到配置的 Wine 引擎；Steam、Overlay 和 Wine 工具不持有读取器。
- 迁移旧常驻启动项，保留独立授权身份和原有游戏参数。新生命周期协议需要升级驱动与读取器，组件更新可能需要重新授权。
- 增加真实 launchd 按需激活回归，继续检查八项配置、输入换算、帧控制、Steam 库解析、未保存状态与发布附件。

# COEditor 1.5.1

- 把实体滚轮读取迁移到独立、保留安装的 COEditor Wheel 组件，Sevoflurane 更新不再改变滚轮权限接收方。首次安装需用户确认新的输入监控授权。
- 保持 HID 管理器运行，支持焦点切换、设备热插拔、授权恢复和打开失败重试；加入心跳过期、进程路由、陈旧事件过滤及实际投递后去重。

- 保留手动参数、已有鼠标移动处理与画面配置，保存普通参数后仍只需重启对应游戏。
- 云端测试共享协议及原有设置、呈现与发布流程。DMG 包含读取器；Wine 驱动需另行更新至本版本匹配构建。未经真人游戏测试的硬件场景不作已验证声明。

# COEditor 1.4.3

- 未保存状态按草稿与保存值比较；刚打开应用、切换游戏和相同状态回写不会误报，改回原值即可清除。
- 阻止禁用控件写入占位值，保留输入继承；同时编辑通用与游戏配置时，正确保存游戏的独立覆盖。
- 新增八项参数的跨进程原子保存测试。普通参数修改只需完全退出并重启对应游戏，无需重启 Steam。
- 补充 Sevoflurane 更新后输入监控授权失效的处理说明。本机已重新登记当前入口，用户确认滚轮恢复每格一次。

验证：云端构建程序在现有 CrossOver 26.3 补丁环境中检查队列 5/16、同步开关、Metal 双/三缓冲与默认回退；正式后台启动的渲染程序确认限帧 60/90、提交节奏 1/2 和统计开关。测试期间 Steam 进程保持不变，原配置完整恢复。这些记录确认参数接入与呈现统计，不代表所有游戏的体验或端到端输入延迟已测量。

本版只更新管理应用，不替换 Wine 驱动或已有游戏配置。DMG 需要已经准备好的匹配补丁环境；启动入口更新后的系统权限恢复可能需要额外重启该入口。

# COEditor 1.4.0

- 移除整套预设与控件锁定，所有参数独立手动调整；旧配置的实际数值保持不变，新配置的画面参数默认跟随游戏。
- D3D11 队列上限可调范围扩展至 1–16；这是允许排队的上限，不会强制积压到指定帧数。

# COEditor 1.3.0

首次公开源码及 DMG 发布，将原“CrossOver 调整器”命名为 **COEditor**。

- 支持通用配置、本地 Steam 游戏选择、显示同步、Metal 双/三缓冲与 D3D11 队列设置。
- 鼠标移动与物理滚轮优化可独立切换；预设锁定数值，自定义模式允许逐项调整。
- 保留现有容器、配置及补丁引擎，应用安装在“应用程序”即可。
- 同步公开 Swift 应用、Wine 补丁、D3D11 代理和构建脚本，采用 LGPL-2.1-or-later。

**安装前提：** DMG 只包含管理工具，需要已有的 CrossOver 26.3 补丁引擎及名为 Steam 的容器。首次建立环境请阅读仓库 `docs/BUILDING.md`。不包含商业运行时或 Steam 数据。

**平台：** Apple Silicon，构建目标 macOS 13+，已验证 macOS 27.0.1。应用为 ad-hoc 签名，未经过 Developer ID 签名或 Apple 公证。

**验证：** debug/release 本地构建、Swift 配置与库解析自测、HID 滚轮/位移累计测试、19 文件 Wine 补丁基线及结果校验、D3D11 代理编译、代码签名及 DMG 挂载校验。GUI 自动操作通道不可用，未将界面点击测试计为通过。

下载 `.dmg`；`SHA256SUMS` 可用于校验。应用配置及原运行环境路径保持兼容。
