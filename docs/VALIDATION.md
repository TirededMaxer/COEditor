# 验证范围

## 已有运行环境的验证

开发期间完成过：

- 用户在 CS2 中确认鼠标移动手感、滚轮每格切一次、帧呈现平稳与输入延迟改善。
- 实际 D3D11 渲染程序验证默认、低延迟、均衡、流畅、关闭同步配置，检查设备创建、独立 swap chain 创建、ResizeBuffers 与队列回读。
- Metal 诊断确认实际同步开关以及 drawable 数量 2 / 3。
- 维护器对已知旧版本恢复、未知变化保留、游戏专用注册与哈希校验。
- Swift 配置读写、继承与 Steam 库格式解析回归；1.4 另验证旧预设标记清理、实际参数保留和独立手动调整。

这不等同于所有 Steam 游戏、反作弊系统或未来 CrossOver 版本已经验证。CS2 的死亡竞赛成功记录是用户实际体验，不代表 Valve 官方认证。

## 仓库整理和发布验证

1.4 发布检查包括干净基线补丁应用及 21 文件结果校验、Swift debug/release 构建、旧配置迁移/独立调整/库解析自测、原生输入与帧控制测试、代码签名校验、DMG 挂载与文件校验。此前真实 Metal 探针验证限帧、两档提交控制及回退；D3D11 程序检查队列 5/16、ResizeBuffers 与呈现统计。队列回读确认接口接受数值，不用于证明实际积压深度；呈现帧时间不等于输入到显示的总延迟。

源码回归不是 GUI 点击验收；本次原生 UI 自动化通道不可用，未把未执行的界面操作计为通过。完整日志和个人路径保留本机，不随仓库发布。具体发布结果记录在各 Release 中。

## 云端验证

从 1.4.1 起，GitHub Actions 在干净的托管 macOS runner 上分别执行应用 / DMG 和 Wine / D3D11 组件构建，不恢复编译缓存。应用作业运行 debug/release 自测、原生输入与帧控制测试、发布附件校验回归，并验证 DMG 内容与签名；组件作业下载官方源码、检查 26 文件基线与补丁结果并从零编译。

构建日志、对应 Wine 源码及二进制保存在云端 artifacts，DMG 来源记录在 BUILDINFO.json；本地项目不保留构建产物与缓存。云端成功不等同于真实游戏、GPU 呈现、系统权限或 GUI 点击验收。

## 1.4.3 本次检查

- 用户确认 1.4.2 候选打开后不再误报未保存；1.4.3 补充通用值变化与游戏显式覆盖的回归保护。
- 在系统设置重新登记更新后的 Sevoflurane 与后台输入监控授权；实际 CS2 日志确认 HID 非独占读取开启，用户确认每格只切一次武器。
- 云端构建的独立 D3D11 程序在已安装补丁环境中回读队列 5/16；Metal 属性诊断确认同步关闭／开启、双／三缓冲及跟随游戏回退。
- 经正式后台启动的新渲染进程分别收到限帧 60/90 与提交节奏 1/2，生成相应实际呈现统计；关闭统计的新进程不再生成记录。测试期间保持同一 Steam 进程，最后原子恢复原配置。
- Wine 组件和 D3D11 代理未替换；当前维护清单内 7 个组件均匹配哈希。以上渲染检查不等于所有游戏的兼容性或端到端输入延迟测试。

## 1.5.1 检查范围

本次增加独立滚轮协议的权限/心跳/设备状态、PID 路由、单次消费、旧事件过滤、环回绕和并发一致性检查，以及读取器状态与原有未保存/参数继承回归。滚轮诊断程序分别记录 WM_MOUSEWHEEL 和 WM_INPUT，需在实际授权后由真人滚动物理鼠标验证；源码和云端构建不代替游戏体验验收。

1.5.0 标签对应未发布候选；其驱动编译通过，附带 Windows 验证程序的宽字符类型检查失败，自动 Release 未执行。1.5.1 修正该错误，保留标签供追溯。

## 1.5.2 检查范围

新增真实 launchd socket 激活检查：空闲无进程、第一游戏唤起、两个游戏共享、崩溃清理、最后一个使用者退出、空闲不自启、无效 PID 创建时间拒绝，以及下次启动再次唤起。该自动测试明确禁用 HID，不读取物理输入或申请 TCC 权限。原有八项参数的独立读写/继承和新进程重读、原生输入换算、帧控制及应用 debug/release 自测继续运行。真实游戏体验和物理滚轮验收需要单独执行。
